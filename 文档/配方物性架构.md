# 配方物性架构与扩展

用途插件只读取统一物性结果、比较用途目标与阈值。配方物性汇总负责实测优先、模型选择和模型依赖；每个模型只实现本指标的计算。功能插件统一通过 `执行(数据上下文)` 由核心流程调用，模型策略使用 `预测(配方, 上游)`，不调用功能插件。

```text
核心系统/配方评估流程.py                 ← 功能插件编排
    颅骨透明化用途层                    ← RI 目标、阈值、未知证据
        配方物性聚合层                  ← 统一结果、实测优先、模型选择
            各个独立物性模型            ← 指标实现和适用条件

插件/配方物性/
├─ 配方物性接口.py                       # 配方输入、物性结果、模型契约
├─ 配方物性汇总.py                       # 聚合插件、注册表
├─ 折射率/
│  ├─ 接口.py
│  └─ Lorentz_Lorenz.py
├─ 黏度/
│  ├─ 接口.py
│  ├─ Grunberg_Nissan.py
│  └─ 理想对数混合.py
├─ 扩散/
│  ├─ 接口.py
│  └─ Stokes_Einstein.py
├─ 渗透/
│  ├─ 接口.py
│  ├─ 理想渗透压.py
│  └─ 非理想活度模型.py
└─ 水活度/
   ├─ 接口.py
   └─ 水活度模型.py
```

## 调用与配置

默认配置位于 `设置/配方物性设置.py`，各指标默认 `measured_only`，保持旧批次行为。可在“配方构建 → 配方物性预测”中逐项选择模型并保存。页面同时支持成分物性、实测值、探针半径、水成分键和校准参数录入。

下面是用于展示接口的合成数值，不是推荐配方或实测物性：

```python
from 插件.配方物性 import 配方物性汇总插件

结果 = 配方物性汇总插件().执行({
    "配方编号": "example",
    "成分": [
        {"成分键": "A", "体积分数": 0.5, "纯物质RI": 1.4},
        {"成分键": "B", "体积分数": 0.5, "纯物质RI": 1.6},
    ],
    "物性条件": {"温度_C": 25},
    "物性模型选择": {"混合折射率": "lorentz_lorenz"},
})
print(结果["混合折射率"]["值"])
```

核心入口 `运行颅骨透明化流程(上下文)` 和 `流程控制器.执行颅骨透明化用途流程(上下文)` 在物性汇总之后生成用途摘要、约束表和特征。旧 `颅骨透明化用途运行器.运行(...)` 作为兼容入口转发到核心。直接调用用途插件需要提供其上游上下文，不再触发隐式重复计算。

配方设置中的 `物性模型选择`、`物性条件`、`物性模型参数` 支持字典或 JSON 对象文本，保存时编码为 JSON；顶层上下文可覆盖批次设置。每个指标可分别设为：

- `measured_only`：没有实测则标记待补。
- 固定方法：只运行指定模型，不会暗中换模型。
- `auto`：先尝试优先级较高的模型，缺数据或不适用时尝试下一模型，保留回退原因。不比较虚构置信度，也不自动训练模型。

所有模式均优先采用有效实测值；无效的已填写实测值标记“输入无效”，不会静默覆盖。未知指标或未知方法报配置错误。

## 输入与方法

| 指标 / 方法 | 必需输入 | 边界 |
| --- | --- | --- |
| 混合折射率 / `lorentz_lorenz` | 各成分 `体积分数`、`纯物质RI` | Lorentz–Lorenz，体积可加近似；RI 温度、波长一致性需由数据来源确认 |
| 混合黏度 / `ideal_log` | `摩尔分数`、`纯物质黏度_mPa_s` | 理想对数混合，明确低可信 |
| 混合黏度 / `grunberg_nissan` | 同上，另加所有非零组分对的 Gij 和参数温度 | 多元使用两两相互作用项；参数不完整时固定方法失败，auto 回退到理想对数混合 |
| 溶液自由扩散系数 / `stokes_einstein` | 上游混合黏度、`探针水动力半径_nm` | D = kBT/(6πηr)，mPa·s 转 Pa·s、nm 转 m；是指定探针的自由扩散，不是组织有效扩散 |
| 渗透压 / `ideal_osmotic` | 每行 `渗透角色`（溶剂/溶质），溶质的 `摩尔浓度_mol_L`、`范特霍夫因子` | Π = RTΣici，mol/L 转 mol/m³；只适合稀溶液初筛，不把溶剂计入浓度和 |
| 渗透压 / `osmotic_coefficient` | 同上，另加当前配方的 `渗透系数` | 用户提供有效修正系数，并非自动拟合非理想模型 |
| 水活度 / `ideal_water_activity` | `摩尔分数`、条件中的 `水成分键` | aw = xw；非理想和电解质体系需修正 |
| 水活度 / `water_activity_coefficient` | 同上，另加 `水活度系数` | aw = gamma_w × xw；仅支持 0–1，不直接推断组织脱水程度 |

模型需要显式 `温度_C`；用途流程默认采用用途配置的温度（默认 25°C）。所有分数分别在 0–1 内且总和为 1（允许 1e-6 舍入误差），不自动归一化或补溶剂。零分数组分不需要纯物性，但不能省略其分数字段。单组分、二元、三元和更多组分使用同一接口。

仅明确的 `v/v%`、`% v/v`、`体积百分比` 可转为体积分数，`mol%`、`摩尔百分比` 可转为摩尔分数。裸 `%`、质量百分比、mM 不会被误当成体积分数；本版不自动换算质量、体积和摩尔比例。其他模型输入中的单位由字段名固定。

校准参数示例（`A`、`B` 为成分键，Gij 按排序后的键存储）：

```python
物性模型参数 = {
    "grunberg_nissan": {"温度_C": 25, "Gij": {"A": {"B": 0.2}}},
    "osmotic_coefficient": {"渗透系数": 0.9},
    "water_activity_coefficient": {"水活度系数": 1.1},
}
```

渗透系数和水活度系数必须适用于当前配方与温度；本版不推断这些系数，也不把缺失范特霍夫因子默认为 1。实测 osmolality 不能直接填入以 Pa 为单位的渗透压字段。

## 结果契约和用途约束

每个结果包含 `指标 / 值 / 单位 / 状态 / 方法 / 模型版本 / 置信度 / 适用范围 / 警告 / 数据来源 / 不确定度 / 依赖`；聚合结果补充配方编号、请求方法、计算条件和模型参数。未校准的公式模型不凭空填写置信度，使用 `None` 并明确警告。扩散保留所依赖黏度的完整结果，传播其警告。

实测 RI 保存在 `混合液实测RI`，模型 RI 保存在 `混合液预测RI`，用途层通过 `混合液采用RI` 计算与目标（默认 1.56）的偏差。预测状态、方法、版本等也进入配方特征，不把预测伪装为实验标签。

可通过用途上下文设置 `用途配置["物性约束"] = {"混合黏度": {"最大": 20}, "溶液自由扩散系数": {"最小": 1e-11}}`（数值仅作配置示例，非实验建议）。约束表分别显示通过、不通过、未知、未设置阈值及证据状态。组织有效扩散、局部滞留、washout、局部和全身毒性保持“未知”，等待独立递送与毒理模块提供证据，不能作为安全通过或总分加分项。

物性和用途约束按批次保存为独立结果表；嵌套警告、依赖、条件、参数以 JSON 写入。既有批次保存策略是同批次覆盖更新，不是不可变的模型运行历史库。

## 新增或替换一个模型

在对应指标目录新增文件（例如 `扩散/实验校准扩散模型.py`），继承该目录的指标接口，声明唯一 `方法`、`模型版本`、`适用范围`，实现 `预测(配方, 上游)` 返回 `物性结果`。模型缺少校准数据或超出适用域时抛出 `输入不可用`；程序错误不会被当作数据缺失吞掉。

向注册表调用 `注册(模型实例)` 并传给 `配方物性汇总插件(注册表)`，或在默认注册表工厂中注册。方法名例如 `experimental_gp_v2`，配置对应指标即可。设置 `自动优先级` 可让 `auto` 优先尝试它；若需要上游黏度，声明 `依赖指标 = ("混合黏度",)`。依赖按需递归计算一次，并检测缺失注册和循环依赖；不需要黏度的校准扩散模型可以没有此依赖。

旧模型继续保留。重复方法名、同指标单位不一致、输出指标/单位/方法/版本违约均报错。换扩散模型无需修改折射率、黏度、渗透、水活度或用途层。AI 和实验校准模型需要真实训练产物后再实现；本次未加入占位预测器、Pareto 优化或 GP/BoTorch 实验闭环，优化仍属于 `插件/实验优化/`。

## 公式依据

- Lorentz–Lorenz 体积分数混合关系：[Density and Refractive Index of Binary Ionic Liquid Mixtures](https://www.mdpi.com/2673-8015/2/4/25)。
- 黏度摩尔分数混合与 Gij：[Grunberg & Nissan, Mixture Law for Viscosity](https://www.nature.com/articles/164799b0)。
- 自由扩散关系及连续介质条件：[IUPAC Stokes–Einstein equation](https://goldbook.iupac.org/terms/view/12260/plain)。
- 理想稀溶液渗透压与溶剂活度关系：[IUPAC osmotic pressure](https://old.goldbook.iupac.org/html/O/O04344.html)。
